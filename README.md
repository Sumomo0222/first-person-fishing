# 湖边钓鱼 · 第一人称沉浸钓场 🎣

一个**打开链接就能玩**的第一人称湖边钓鱼互动网页：你坐在木栈桥头，手里握着鱼竿，
眼前是浮漂、波光与远山。抛竿、等浮漂下沉、收线，把奇妙渔获收进「湖边图鉴」——
而每钓起一次，湖边的时间就会向前走一段：从清晨薄雾一直钓到月光满湖。

- **在线体验**：<https://sumomo0222.github.io/first-person-fishing/>
- **纯静态**：HTML + CSS + 原生 JavaScript，无框架、无构建、无外部图片——
  鱼竿、手部剪影、木栈桥、浮漂、渔获、远山全部由 CSS / SVG 手绘。

## 本地打开

无需任何构建工具，二选一：

```bash
# 方式一：直接用浏览器打开
open dist/index.html          # macOS
# 方式二：起一个本地静态服务（推荐，路径行为与线上一致）
cd first-person-fishing/dist
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```

## 交互说明

一次完整的钓鱼由主按钮驱动，共四个节拍：

1. **抛竿** — 点「🎣 抛竿」：鱼竿轻甩回弹，浮漂沿抛物线飞向湖面，
   落水激起水花与涟漪，鱼线始终连接竿尖与浮漂；
2. **等待鱼汛** — 浮漂随波轻晃，途中可能有一次「假口」轻点（小心别上当）；
3. **收线** — 浮漂猛地下沉、弹出红色「!」提示、按钮变红闪烁：在约 1.6 秒
   咬钩窗口内点「❗ 收线！」，过早收线会空竿，过晚则脱钩；
4. **渔获** — 渔获从浮漂附近的水面里跃出（弧线跳向镜头），居中弹窗展示，
   自动存入图鉴，时间推进到下一阶段。

其他交互：

- **📖 湖边图鉴**（右上角）：随时查看收集进度「已收集 x / 10」；
  未钓到的是黑色剪影 + 问号，钓到后点亮并标出稀有度；
- **再钓一次 / 再抛一竿**：弹窗内一键再来；
- 进度与时间阶段存在 `localStorage`，刷新页面不丢失。

## 第一人称视角如何实现

整个场景是一个全屏分层画布，由远及近七层叠加，模拟坐在栈桥上的视野：

| 层 | 内容 | 实现方式 |
|---|---|---|
| 远景 | 天空渐变、太阳/月亮、星星、云、飞鸟、薄雾 | CSS 渐变 + 小元素动画 |
| 远景 | 湖对岸山影、树影 | 内联 SVG（`preserveAspectRatio="none"` 铺满） |
| 中景 | 湖面渐变、波纹、日光/月光水路、碎金光斑、小船、萤火虫 | CSS 渐变动画 + JS 生成的微粒 |
| 水面特效 | 涟漪、水花、跃出的渔获 | JS 动态插入元素 + Web Animations API |
| 近景 | 木栈桥（透视板缝）、系船柱与缆绳 | SVG 梯形透视 + CSS 木纹叠加 |
| 钓组 | 鱼竿（两段式带弯曲）、鱼线（垂度曲线）、手部剪影、渔轮 | 单个全屏 SVG，`requestAnimationFrame` 每帧重算 path |
| UI | 时间阶段、图鉴、主按钮、弹窗 | 固定定位 HUD |

透视的关键：鱼竿的持竿点固定在画面右下角（约 88% 宽、96% 高处），
竿尖落在中上部，`atan2` 计算静息角；抛竿时角度按「后摆→鞭打→回正」的时间包络旋转，
竿尖坐标实时解出，鱼线从竿尖到浮漂用二次贝塞尔曲线绘制垂度（抛竿时绷直、
水中松弛、收线时拉紧）。因此鱼竿、鱼线、浮漂三者始终严格联动，形成明确的第一人称纵深。

渔获出现位置也遵循这一规则：从浮漂所在的水面坐标起跳（带水花与白闪），
沿弧线跃向镜头方向放大——绝不会从屏幕中央凭空出现。

## 时间变化与图鉴

**时光五阶段**：`清晨湖面 → 正午晴湖 → 黄昏风起 → 暮蓝星升 → 月光时刻`。
每完成一次钓鱼（含渔获弹窗关闭）推进一格，循环往复。

实现上，每个时段是一个 `body.phase-*` 类，集中定义约 20 个 CSS 自定义属性
（天空三段渐变、湖水三段、远山两层、木桥色、日/月位置与光晕、水路颜色与位置、
星星/萤火虫/船灯可见度、浮漂夜间光点……）。这些变量用 CSS `@property` 注册为
`<color>` 并在 `body` 上声明过渡，切类时所有颜色平滑插值——天空、湖面反光、
远山明暗、浮漂光点一起在 1.8 秒内完成换幕。

**湖边图鉴**共 10 种奇妙渔获，各有名称、稀有度（常见/少见/稀有/传说）、
出没时段与一句湖边记录。每次咬钩只从**当前时段的鱼池**里按稀有度加权抽取——
想集齐图鉴，就得在不同的时间里钓鱼：例如「月亮贝壳」「许愿石」只在月光时刻出现，
「旧船票」偏爱清晨与黄昏。

## 部署

`dist/` 是纯静态站点，任意静态托管皆可：

```bash
# GitHub Pages（本项目使用的方式）
# 仓库需含 dist/ 与 .github/workflows/deploy.yml（Actions 部署 dist/）
git init && git add . && git commit -m "init"
git remote add origin git@github.com:<user>/first-person-fishing.git
git push -u origin main
# 然后在仓库 Settings → Pages → Source 选 GitHub Actions

# 或任意支持静态目录的平台：Vercel / Netlify / Cloudflare Pages
# 构建命令留空，输出目录填 dist
```

## 可以继续优化的方向

- **手感**：收线改为连续点击/长按蓄力的搏鱼小游戏，加入断线概率与张力条；
- **生态**：更多渔获与组合（鱼骨、芦苇精、雾中灯笼…），引入季节或天气系统；
- **氛围**：WebAudio 合成环境音（水声、虫鸣、电台杂音），或 WebGL 水面反射；
- **社交**：导出「今日渔获卡片」图片，生成分享链接；
- **工程**：拆分 ES Module、加入 Service Worker 离线缓存与 PWA 安装。
